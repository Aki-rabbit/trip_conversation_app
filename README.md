# Trip Phrases

海外旅行で使える「気持ちの一言」を、現地の言葉でさっと確認できるフレーズカードアプリ。

## このアプリについて

学習よりも実践が目的です。

旅行先で「英語に入る前に、気持ちの一言を現地の言葉で渡す」ための道具です。
正確さ・文法よりも「迷わず・失礼にならず・あたたかい体験」を重視しています。

### 具体的な体験イメージ

- レストランを出るときに店員さんへ「Grazie.」と言える
- その一言で相手の表情が少し和らぐ
- 言葉が出てこない不安が軽くなる

## 機能

### Intent（意図）ベースの分類

「どこで使うか」ではなく「何を伝えたいか」でフレーズを分類しています。
「感謝」は、レストランでもホテルでも同じ言葉を使えます。

現在対応している Intent:
- **Greeting** - こんにちは・挨拶
- **Thanks** - ありがとう・感謝
- **Sorry** - ごめんなさい・謝罪
- **Please** - お願いします
- **Goodbye** - さようなら

### 対応言語

- イタリア語
- ドイツ語

### フレーズカード

- シンプルな表示で迷わない
- 音声読み上げ機能（Web Speech API）

### カスタマイズ機能

- 自分だけのカテゴリ（Intent）を追加
- 自分だけのフレーズを追加
- カスタムカテゴリ・フレーズは削除可能
- データはLocalStorageに保存

## 技術スタック

- React + TypeScript
- Vite
- 状態管理は `useState` のみ（シンプル設計）

## 開発の経緯

最初は「レストラン」「ホテル」などの Scene（場面）で分類する設計でした。
しかし「ありがとう」はどの場面でも同じ言葉になることに気づき、Intent（意図）ベースの設計に変更しました。
